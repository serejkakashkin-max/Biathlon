G1 и G2 одобрены владельцем. **M13 открыт; WP-176 PASS, WP-175/177/178 открыты.** Единственная production
трасса — Woodland. WP-170–174 отложены по сокращению числа трасс. Master Plan
сохранён. Следующий Windows билд — только после общего пакета правок, затем
владелец проводит hands-on проверку.

WP-175: четыре профиля снега прошли физические component tests 10/10 и полные
одиночные Woodland Sprint с точным replay 4/4; пять погодных привязок прошли
Unity PlayMode 5/5. Полный Mass Start 30 завершён на icy_fast, Sprint 40 и
квалифицированный им Pursuit 40 — на fresh_soft. Дополнительно полные
Sprint→Pursuit 40 на packed_neutral и Mass Start 30 на wet_slow PASS.
Матрица всех условий,
полносоставный replay, визуальная и performance-оценка остаются открытыми.
[Отчёт](reports/TASK_WP175_WOODLAND_CONDITIONS_01_REPORT.md).

WP-176: PASS по production content. Один сезон Woodland содержит 16 стартов:
6 настоящих Sprint→Pursuit пар и 4 Mass Start. Полные 52 недели с
сохранением после каждой и все 16 authoritative гонок прошли в Release .NET
1/1; финальные тесты выбора нового/старого календаря 3/3 .NET и 3/3
точечных Unity EditMode. Старые сохранения выбирают прежний календарь по ID;
новая карьера явно выбирает Woodland. UI подключения остаётся для M14.
Прежний длинный native запрос без completion receipt не считается PASS.
[Отчёт](reports/TASK_WP176_WOODLAND_CAREER_CALENDAR_20261007.md).

WP-177: зафиксирован воспроизводимый baseline авторских данных Woodland.
Главный круг 1 200 м, набор/спуск ≈27,9 м, длинный спуск 168 м с падением
11,7 м; физический уклон и визуальная высота согласуются в пределах 1 см на
сегмент. Трасса визуально всё ещё требует проверки читаемости спуска в chase
camera. В одном fixed-seed production поле из 30 спортсменов
победители прошли Sprint/Pursuit/Mass Start за 10:23/13:04/15:08; полные
прогоны 2/2 и 1/1 PASS. Парная проверка Woodland до стрельбы: climbing
30→90 сэкономил 6,35 с к отметке Main 650 м при одинаковом управлении;
expert/developing AI на одном спортсмене дал 851/341 решений, но только
0,05 с разницы до Main 1 000 м в одиночном проезде. .NET 2/2 и Unity MCP
EditMode 2/2 PASS. Это ещё не окончательный баланс: нужны измерение
остановок в трафике, сложность полной гонки и читаемость спуска.
[Отчёт](reports/TASK_WP177_WOODLAND_COURSE_BASELINE_20261007.md).

WP-178: после отменённого долгого EditMode прогона снят скрытый диагностический
снимок памяти Editor. Это не benchmark игры: ~27,5 ГБ — ёмкость Mono heap,
а текущий Mono-used ~166 МБ. Нужны изолированные скрытые замеры Mass Start и
broadcast после общей пачки M13. [Отчёт](reports/TASK_WP178_EDITOR_MEMORY_DIAGNOSTIC_20261007.md).

некорректный второй спортсмен отменяет весь пакет. .NET 8/8, расширенная
