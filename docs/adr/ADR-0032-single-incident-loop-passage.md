# ADR0032 — Same-loop passage through an unused branch guard

2026-10-05. Accepted correction to the optional complete world-body policy of ADR0031.

Woodland Main1200m is closed. The start-join port at Main0m has an18m incoming guard,
which also covers the end of each later lap. Two Main athletes could therefore be
held before Main1181.25m even when their bodies occupied separate lines. The start
continuation exception applies only to the first paid start passage. An unused start
branch must not impose a one-athlete lease on ordinary later-lap Main traffic.

For an optional field with the exact captured full world geometry, a junction may
share two traces that remain entirely on one loop when that loop has exactly one
incident port in the junction. Every paid receipt, old/new tail and periodic seam
still passes the existing complete world-body proof. The ordinary same-loop
occupancy check is also retained. Other branch bodies are checked separately by
the same joint transaction. There is no teleport, body shrink or priority exemption.

Multiple incident ports on the same loop retain the self-crossing guard. Unknown
geometry, a mixed-loop trace/tail or an unsplit wrap cannot grant compatibility.
The world context marker is v3 and binds this rule. Policy-absent legacy behavior
remains unchanged. Archived v2 evidence remains associated with its frozen build.

The reduced guard reproduction fails before this change and passes afterward,
including separated bodies across the closed endpoint, touching bodies and the
policy-absent control. The eligibility query has a zero-allocation test. Actual
Mass30 completes at22987ticks and passes exact persisted state/event/result replay
without AI. Its maximum stationary interval falls from872 to378ticks; the remaining
maximum is an approach contact at mat06, not the corrected later-lap Main lease.
No claim of eliminating every traffic stop is made.

The owner also authorized rare physical contacts. This correction retains the
current strict contact solver; it does not implement that forthcoming shared
heading/contact policy or full manual steering.
