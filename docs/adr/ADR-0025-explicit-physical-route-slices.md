# ADR-0025 — explicit physical competition route slices

Status: accepted for TASK169K, M13. Extends ADR0003/0011/0024; legacy schema1 routes and null-option replay contexts retain their existing behavior.

One physical Main loop cannot simultaneously be 3000m, 2500m and 3333.333m. Production formats therefore use schema2 ordered, positive, nonwrapping slices of existing physical loops, with whole-millimetre endpoints. A section exposes both its cumulative race start and physical loop start. Sampling, terrain boundaries, checkpoints, AI range previews, range path replacement and penalty traversal apply that offset. Repeated occurrences retain physical loop identity.

Different-loop boundaries require a named directed coincident connection with exact incident endpoints. Same-loop boundaries are adjacent or a closed-loop terminal-to-zero wrap. A finite connector must have its own counted geometry. `PhysicalRoutePlanValidation` is a shared cold Domain contract used by authoring and simulation; no Unity presentation data grants connectivity. Closed terminal coordinates normalize to zero for physical seam identity. Shooting laps include exactly one complete range/rejoin bundle and retain actual travel after rejoin before the lap boundary.

The optional schema2 venue `format_bindings_resource` catalog binds exact profile and route resources, venue/track IDs, distances, laps, competition format, directed topology and physical penalty distance. Only a validated schema2 route can certify an additional open competition branch. An unrelated open loop still fails the world validator. The production factory rejects profile/route pairs differing from a bound catalog. Static world validation separately checks each seam, actual chord length, grade, corridor overlap and local body-clearance guards; the catalog is not runtime admission evidence.

Production catalog races explicitly capture the set of reachable physical loops from every route slice, every possible range lane slice, the penalty loop, and the authored start approach. A junction region remains exclusive when at least two of its incident ports are reachable. Multiple ports on the same used loop preserve a real self-crossing. An unreachable alternative-format branch cannot make ordinary Main traffic exclusive. Full source region indices and definitions remain in the replay context, together with the sorted used-loop snapshot and policy. Physical points outside that snapshot throw; the binding never silently omits traffic presented to the guard. The null binding retains the legacy all-port behavior. This opt-in prevents an unused Sprint/Pursuit fork from stopping a Mass Start field while preserving all reachable admission, private-lane and exit guards.

Catalog Sprint/Pursuit fields may contain up to their profile capacity (60) with 30 authored mats. `PhysicalRangeReservations` assigns the lowest free private lane in accepted fractional arrival order and releases it only after the complete body and retained private tail have cleared that lane. Release and admission changes are joint prepared/committed state, independently revalidated against final accepted motion. Arrival rank and lane ordinal are distinct. Context includes the complete resource, occupancy and clock binding. Mass Start and legacy factories retain their prior distinct-lane rules. Recorded commands derive the same reservations during replay; no external lane decisions are injected.

Venue01 keeps its 3000m Main identity and range geometry. Pursuit replaces a 1383.344m Main interval with an 883.344m actual traverse. Sprint replaces 180m with a 513.333m actual extension. Three whole-mm Sprint laps leave 1mm; its last lap includes actual Main0–0.001m finish travel after the closed wrap. The authoritative profile remains exactly 10km. The finish observation must use that physical endpoint. Route and world geometry are never rescaled to conceal rounding.

These opt-in routes change production race outcomes through actual geometry and terrain. They require deterministic complete races, recorded replay, dense traffic and Unity presentation acceptance before WP169 completion. No athlete capability, difficulty, shooting hit geometry or hidden speed/power multiplier is changed by this decision.
