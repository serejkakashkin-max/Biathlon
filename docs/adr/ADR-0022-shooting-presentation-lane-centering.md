# ADR-0022 — Центрирование видимой стрелковой позы

2026-09-27, owner corrective directive для G2. Уточняет presentation boundary ADR-0020, не меняет ADR-0014/0017 и правила стрельбы.

В Mass Start наблюдение может сохранять лыжное боковое смещение 1,6 м после остановки на назначенной физической ветви рубежа. Прямое применение этого смещения к модели ставило её рядом с ковриком. В обзорном тесте была отдельная ошибка: произвольная координата x=-10 вместо центра существующего коврика.

`RangeMatPresentation` строит 30 ковриков по `PhysicalRangeLaneDefinition` и той же `TrackVisualDefinition`, что используется proxy. Продольная точка — `track.Range.FiringLine - lanes.Entry`. Номера из наблюдений однобазовые. Коврики не имеют физической роли.

При активной стрелковой фазе proxy умножает видимое боковое смещение на `1 - SmoothStep(existing rifle progress)`. В Setup происходит плавное центрирование, Aiming/BoltCycle стоят точно на оси lane, Exiting возвращает исходное смещение. Точка остановки и ориентация берутся из физической ветви. Pose drivers по-прежнему не имеют root motion.

Снимок, дистанция, физическая занятость, replay, sight ray и resolver остаются неизменными. Dedicated shooting camera продолжает читать authoritative sight. Это явная ограниченная коррекция видимой постановки; она не исправляет и не скрывает проблему очереди перед общим входом рубежа.

Регрессия проверяет реальные Sprint/Mass Start prone и standing, соответствие lane/loop, положение таза/стоп внутри коврика и неизменность tick/lateral/snapshot после рендера. Отдельные review fixtures проверяют границы существующего benchmark-коврика.
