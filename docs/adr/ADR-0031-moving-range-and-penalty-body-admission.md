# ADR0031 — Body-safe moving range and penalty departures

Status: Accepted implementation; owner hands-on review of the new build remains pending.
Date:2026-10-05. Authority: owner traffic/guidance/tuck directive; ADR0028–0030 remain applicable.

The short Woodland course exposed a permanent circular wait between the shared exit aisle,
penalty return and incoming private range paths. Exclusive junction/exit leases held bodies
that could occupy separate real lines. Simply skipping those guards is unsafe: branch bodies
can contact before their centre lines reach a named junction, and incoming seam tails remain
occupied after a transition. The30-body reproduction eventually stopped the entire field.

The optional schema2 shared-apron definition now declares parallel post-shoot departures
and explicitly names the penalty merge junction. Its exact captured track, visual knots,
selected paths, body, junctions, connections and numerical validation policy bind a complete
world projection map. The field supplies its existing paid, fractionally timed receipts and
retained incoming tails. A lease may yield only after the complete swept bodies are proved
separate. Cross-branch contact is checked before the point guards; same-loop spacing remains.
Unknown geometry, unsplit wrap, contact, an ambiguous rotation or missing provenance blocks.
Shooting and retained mat-pose tails retain the conservative pose envelope. Ordinary ski
bodies retain the configured rectangle. No body/guard shrink, teleport or speed bonus is used.

Indexed projection skips only nonintersecting knot intervals. Reference tests compare its
bounds exactly with the exhaustive algorithm at knots, adjacent nanometres and interior
sweeps. Periodic penalty seams include the actual incoming/outgoing tangents and shortest
rotation. Existing public seam/apron arithmetic is unchanged when the optional policy is absent.

AI may select a bounded paid lateral escape after observed stationary travel, then hold that
goal briefly. Queries include periodic bodies and accepted tails; a clipped no-op is not an
escape. Private approach/shooting remains centred. Post-shoot private departure may escape
within its unchanged width. AI commands pay normal effort/propulsion costs and the accepting
field repeats all simultaneous checks. The same bounded escape remains available to a
stalled actor on Main after the range planner finishes; otherwise an actual qualified
Pursuit schedule forms a circular Main/penalty wait. Draft intent cannot override an
active paid escape. The context marker explicitly identifies this v2 scope. Private
approach/shooting and shared-start handling remain separate. Player commands are preserved. IBU7.1.4 priority is
limited to athletes on/exiting the penalty loop over athletes entering that loop; it grants no
collision exemption or blanket priority over all range departures.

For the first paid Start/Main continuation only, AI may preview a destination lateral
line with the same exact body/tail geometry. This is a read-only intent choice, never
an admission grant: the normal simultaneous field step still accepts or rejects travel.
A bounded overtake goal survives the curved seam so the entire29-athlete rear field
can bypass a stationary player. No perception is joined across later Main laps.

The world proof is appended to the existing encoded context array without wrapping and
escaping its complete legacy contents again. Exact prior values and capacity limits remain.
The optional policy, algorithm markers and geometry are recorded in deterministic context;
accepted inputs, public state and ordered field events are replayed without running AI.

Owner range assistance is a separate bounded input adapter:3m final private approach and1m
initial departure. Original cyan arrows read the selected physical path and never move or
reserve an athlete. Player downhill tuck uses the existing shared physics; AI activation is
venue-scoped so locked career/balance scenarios retain their original global policy.

Evidence and rejected reproductions: `artifacts/owner-traffic-guidance-20261005/` and the
three corresponding TASK reports. M13/WP175–178 and full manual-heading integration remain open.
