# Venue01 full format terrain/ribbon clearance

The previous knot-only test missed a real rendered geometry defect. Its terrain interpolation was the same affine terrain triangles used by the renderer. The 1,358 authored centre knots had positive gaps of 0.016555–0.094949m; exact centreline interiors reached 0.003463m. Across the complete ribbon width, terrain protruded 0.177613m into the Sprint branch near its 18.780m knot. Main and Pursuit edges also intersected terrain. Nearest centre-edge height selection could choose a higher neighboring course across a shared lateral footprint.

The presentation generator now reconstructs every `TrackRibbonBuilder` row: visual knots, authoritative segment boundaries, regular sample spacing, outgoing turn tangent/width, and terminal closed seam. It uses the same float32 Vector3 conversion/arithmetic. For each actual ribbon/terrain triangle overlay, it computes the worst clearance violation at the overlay polygon vertices and conservatively lowers all three terrain grid vertices by at least that amount. Shared grid vertices maintain identical tile borders. Base samples outside affected course cells retain their original values; explicit tree heights are regenerated from the final triangles. Track, paths, routes, race motion and shooting geometry do not change.

The independent verifier reconstructs the ribbon separately and measures the actual float32 terrain vertices over every overlap polygon. For the corrected format draft it checked 8,524 nondegenerate ribbon triangles and 268,110 overlay vertices: zero buried triangles, minimum gap 0.029997205m, maximum gap 0.344666062m. The cap lowered 7,583 of 406,785 unique terrain vertices, by at most 0.207614595m. Centre-knot gaps now span 0.030000–0.192159m; a universal 0.10m upper gap claim would be false.

The serialized verifier passes 11,490 identical tile-border checks, 26,382 explicit tree height/canopy checks and all 30 target geometry bindings. The three focused Python tests cover buried lateral edges despite safe centre knots, an interior terrain peak missed by endpoints, shared grid serialization, terminal width and float32 geometry. The new `ProductionTerrainContactTests` PlayMode test consumes the actual environment terrain mesh vertices/indices and actual `TrackRibbonBuilder` meshes, checks complete coverage and every triangle-overlap extremum against a 0.025m minimum, verifies shared borders, and checks source immutability. Root must run it after import.

The maximum 0.345m gap may produce a visible lip or require edge skirts. Camera inspection, contact presentation, performance and owner acceptance remain pending. Static clearance PASS is not visual PASS.
