# WP169 directed passage regression fixture

These nineteen exact JSON snapshots were copied from the accepted production
course backup taken before the owner requested shortened Woodland geometry.
`provenance.json` records every original file hash.

The directed passage tests contain measured coordinates on the historical 3km
Main and 883.344m shortcut. Those numerical witnesses must retain their exact
original track, route, topology and resource binding. This fixture keeps their
strict collision, rotation, provenance and allocation assertions executable.
It is outside Unity Resources and cannot be selected as game content.

Current compressed-course acceptance is verified separately with the actual
Assets resource catalog, current complete races and persisted replay. A fixture
test pass does not qualify the current course.
