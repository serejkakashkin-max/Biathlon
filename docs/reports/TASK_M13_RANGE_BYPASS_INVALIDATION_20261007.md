# M13 — повторная проверка физического объезда у рубежа

Дата: 2026-10-07. WP-177 и M13 остаются OPEN. Сборка для владельца ещё не выпущена.

Seed 321 опроверг ранее полученный положительный результат seed 123. На отдельном кандидате с 80-метровым окном спуска спортсмен на `mat_13` и сосед на Main блокировали друг друга: к диагностическому пределу 25 000 тиков непрерывная остановка достигла 21 792 тиков. Действующие Assets воспроизводят ту же пару. Сравнение с кодом до `77214c0` показало, что реактивное сохранение линии усилило дефект: AI уже выбрал физически доступную линию справа, но последующее правило заменяло её текущей линией. В измеренном состоянии Main 1057,237 м свободный правый шаг существовал, выбранная цель была 2,15 м, а опубликованный запрос оставался 0,35 м. [Индекс 13 отвергнутых опытов](../quality/m13/wp177-descent-review-20261007/wp177-seed321-traffic-diagnosis.json).

Исправление позволяет проверенному боковому шагу пережить реактивный fallback. `FirstRangeApproachDoesNotCancelAnAvailablePaidBypass` воспроизводит реальную первую стрельбу поля 30, seed 321; тест наблюдался красным до исправления и зелёным после. Окружение поля нужно для формирования исходной встречи, поэтому тест не подменяет её телепортированной парой. Скрытый Unity EditMode выполнил этот же случай: 1/1 PASS.

После освобождения пары появился независимый затор ширины на Main 1014,797 м. Проверка объезда учитывала текущий широкий подъезд, но не будущий узкий проход к назначенному коврику. `ApproachBypassLookaheadRespectsTheAssignedNarrowMatPath` воспроизводит ошибку одной реальной гонкой: цель 1,3 м помещается сейчас и не помещается через 5 м. Тест наблюдался красным, затем зелёным; скрытая Unity EditMode 1/1 PASS. `FitsRouteEnvelope` теперь проходит все границы выбранного пути в заданном горизонте, включая частный поворот. Авторитетный приём движения использует прежний полный габарит и прежние проверки.

Удерживаемая до секунды цель объезда могла стать занятой после движения соседа. Теперь AI каждый тик повторно проверяет ширину на полном горизонте, ближайший боковой шаг и ближайшее продвижение вперёд. Короткий выход из затора может ослабить только дальнее наблюдение тел, а не ширину выбранного пути. Последняя проверка вперёд существенна: без неё seed 123 на короткой трассе всё ещё давал 504 тика остановки штрафного круга, хотя боковой переход был свободен. Для выбора стороны используется мировое положение фактического блокирующего тела, включая соседнюю ветку; номера метров разных веток не сравниваются. Чтение не перемещает тела и не разрешает контакт.

Владелец 2026-10-07 явно одобрил измеренные 193 actor-ticks на выходе предыдущего промежуточного варианта. Только этот суммарный предел изменён с 180 на 193; полное завершение, максимум непрерывной остановки 75 тиков и суммарные остановки частных путей ≤700 сохранены. Диагностические переменные seed/предела тиков/раннего обнаружения лишь сокращают отвергнутый прогон; досрочная остановка всё равно проваливает требование завершения. Стандартный seed остаётся 123.
