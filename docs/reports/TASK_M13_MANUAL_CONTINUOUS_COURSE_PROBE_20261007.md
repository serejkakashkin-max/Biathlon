# M13 — непрерывный допуск AI к поворотам Woodland

Статус: ограниченный кандидат ручного мирового движения; playable Pack host и M13 остаются открытыми. Windows билд не выпускался.

После дискретного force/yaw probe подключена уже существующая консервативная проверка `ManualRouteTubeSweep` к **каждому** тиковому кандидату на первых 940 м Woodland Main. Она учитывает полное тело, edge clearance, резерв угла авторской вершины и погрешность траектории. Проверка обнаружила касание внутренней границы около 903 м, которое конечные сэмплы не показывали. Увеличение верхней дальности обзора 22→28 м ухудшило вход; 18 м устранили этот конкретный выход при 200 и 300 Вт без изменения общего физического yaw/grip solver. Параметр находится в версионированном `manual_ai_steering_v2.json`; игровой host пока его не читает.

Release .NET тесты локальной проекции, AI и tube — 32/32 PASS; скрытая Unity EditMode проверка окончательного набора AI — 10/10 PASS, свежих ошибок Console нет. [TRX](../quality/m13/m13-manual-ai-tube-final2.trx). Случай 400 Вт сохранён в тесте как ожидаемый **отказ консервативной проверки полного тика** около 72 м, а не как успешный проход: пока коридор не доказан, движение нельзя принимать. Это не утверждение о фактическом столкновении в этом месте. Чрезмерно быстрая реакция 0,25 с также ломала несколько скоростей. Это подтверждает необходимость AI планирования усилия/торможения перед поворотом и проверки разных спортсменов и snow-профилей.

Это не гонка: нет составного контакта, начала, рубежа, штрафного круга, сквозной транзакции Pack, player input или replay v2. WP-177 и M13 открыты.
