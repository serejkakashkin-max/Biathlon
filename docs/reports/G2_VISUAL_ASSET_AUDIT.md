## Лицензионные основания и границы

- [Blender demo assets](https://www.blender.org/download/demo-files/) прямо обозначает Human Base Meshes1.4.1 как CC0; [Skin Stamps](https://studio.blender.org/training/realistic-human-research/reprojection-sculpt-layers/) также CC0. Лицензия MPFB как программы не автоматически задаёт лицензию каждого набора данных; для hero выбран подтверждённый Blender base.
- [Poly Haven](https://polyhaven.com/license) разрешает commercial use, модификации и перераспространение assets под CC0. Не копируем branding сайта или рекламные renders.
- Все6 Sketchfab моделей подтверждены API автора/модели как CC BY4.0; [условия CC BY](https://creativecommons.org/licenses/by/4.0/) требуют attribution, ссылку на лицензию и указание изменений. Удаление сторонней маркировки не удаляет обязательные авторские credits.
- [Adobe FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html) разрешает коммерческие игры. Это не разрешение перепубликовать библиотеку raw animations; Mixamo остаётся local reference/retarget source, не training data.
- Rokoko страницы разрешают commercial project use. Не выводим из отсутствия запрета право выкладывать исходную motion library; выбранные clips/derivatives остаются локальными, до отдельного основания для публикации.
- [Renderpeople T&C](https://renderpeople.com/general-terms-and-conditions/) распространяются и на free data; разрешают games, но ограничивают доступ/передачу 3D data, включая модифицированные. LFS не снимает этих ограничений. Допустим controlled local import для сборки игры, а в Git — только собственный importer/recipe и manifest; restricted FBX/meshes/textures туда не попадают.
- 3dassets pack pages декларируют CC0 в JSON-LD. Generated/invented marks всё равно заменяются собственными нейтральными панелями; low-poly kit рассматривается как строительные детали, а не гарантия визуального качества.

## De-branding acceptance

Для goggles G2-032: отказаться от всех исходных colour/normal textures с band typography; не переносить `road-rage_regular1.png`. Проверить mesh islands и embossed/text geometry, удалить маркировку в геометрии, сделать нейтральные материалы, осмотреть спереди/сзади/слева/справа/сверху и в chase/shooting. Нельзя объявлять de-branded только по переименованию материала. Если форма сама узнаваемо воспроизводит знак — изменить геометрию или отклонить компонент.

Для каждого Sketchfab/stadium/crowd source: визуально проверить albedo, normal/height (логотип может быть в normal), mesh parts и generated signage. Только после этого фиксировать **APPROVED IMPORTED DERIVATIVE** с source SHA, derivative path, modifications и capture evidence. Сейчас de-branding ещё не выполнен.
