# M13 acceptance, faster A/D and M14 entry

2026-10-11. The owner accepts the latest M13 version, requests sharper A/D, and
authorizes starting M14 without producing another test build. M13 is closed by
owner acceptance; M14 is in progress. This record supersedes earlier operational
OPEN/not-started entries without changing their historical text.

## Delivered

The production keyboard steering rate is 4000 units/s, previously 2000. Full
deflection now arrives in five 20Hz ticks (0.25s), rather than ten (0.5s). Left
and right corrections, reversal and neutral release use the existing command
builder and shared snow/steering authority. Physical yaw/grip, analog steering,
AI recovery/braking, athlete balance and the accepted graphics remain unchanged.
Keyboard command histories change deterministically with the new tuning.

The first WP-179/WP-180 slice includes a Unity-free front-end session, validated
independent career profiles, and the retained Unity UI Toolkit main menu. New
Career creates and saves the real production career; Continue restores its
calendar and RNG state exactly, including legacy calendar identities. Settings
provides Russian/English and three text sizes, with visible keyboard/gamepad
focus. The career overview shows real state and the upcoming event. It does not
invent race outcomes or advance a week.

`Assets/Scenes/FrontEnd.unity` is generated and preview-validated. Open scenes,
build settings and the previous race entry are preserved. No manual Inspector
setup is required. Profiles use the platform persistent data folder, separately
from UI preferences. A failed save/load is readable and preserves existing data.

Main files/systems:

- `Assets/Resources/Biathlon/device_control_gameplay_v3.json` and focused device/
  device-to-snow/native adapter tests.
- `Assets/Scripts/Presentation/`: session, profile persistence and localized text;
  assembly and portable project references.
- `Assets/Scripts/Unity/Presentation/FrontEndMenu.cs`, `FrontEndTheme.cs`;
  `Assets/Resources/Biathlon/UI/` theme, text and default UI Toolkit stylesheet.
- `Assets/Scripts/Unity/Editor/FrontEndAuthoring.cs`, generated front-end scene,
  six core profile tests and six native menu tests.
