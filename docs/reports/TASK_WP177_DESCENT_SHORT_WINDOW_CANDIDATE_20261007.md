# WP-177 — короткое окно спуска Woodland, кандидат

Статус: **проверенный рецепт, не импортирован в production ресурсы**. WP-177 и M13 открыты; Windows билд не собирался.

На Main старый рецепт оставлял два последовательных прямых ребра общей длиной 140 м с падением 9 м. В рецепте единственной production трассы окно сокращено до 80 м. Оба прямых окна (подъём и спуск) остаются геометрически точными: они нужны для стыков Sprint/Pursuit, но окружающие участки получают больше пространства для видимого изменения направления и рельефа. Крайние 40/60/70/75 м были проверены в отдельных черновиках; при 75 м Sprint extension уже достигает уклона 0,658, что нарушает 0,25 authoring bound. При 80 м максимум Sprint 0,100504, Pursuit 0,113219.

Проверки кандидата: `test_short_outer_course.py` 10/10 и `test_stadium_placement.py` 8/8 PASS. Независимая проверка сериализованных маршрутов подтверждает неизменные оплаченные дистанции: Main 1200 м, Mass Start 6000 м, Sprint 4200,001 м и Pursuit 5000 м; 69 направленных стыков с нулевым мировым разрывом. Пересозданные terrain/forest данные проходят `verify_environment.py`: 36 terrain tiles, 33 forest groups, 8484 деревьев, минимальный полный зазор к кроне 3,006956 м; 0 скрытых под terrain дорожных треугольников.

Полная статическая production политика пока не проходит: в старом генераторе компактного рубежа 1282 диагноза (1218 `junction.unprotected_crossing`, 60 `range.shared_entry_gate`, 4 `junction.guard_extent`). Для сравнения текущие игровые Assets отдельно дают 638 `junction.guard_extent` диагнозов. Это не одно и то же множество, поэтому нельзя объявлять полный static PASS или автоматически копировать весь сгенерированный пакет поверх действующей трассы. Текущие guard/traffic коррекции рубежа нужно перенести в единый генератор и повторить валидацию. Затем требуются Unity compile/Console, EditMode/PlayMode, детерминированный полный Sprint/Pursuit/Mass Start, AI проезд, движущийся Game View спуска и визуальная проверка окружения. До них длина 80 м остаётся кандидатом.

Черновой вывод находится в ignored `artifacts/wp177-descent-trial/`; проверяемые исходники и тест в Git. Authoritative gameplay, реплей и загруженные Unity ресурсы этой правкой не меняются. Баланс гонки в существующем билде неизменен.
