# M13 — first Woodland manual-steering policy candidate

Date: 2026-10-07. Status: validated standalone candidate, **not a playable host switch**. M13, WP-175/177/178 remain open.

`manual_ski_steering_v2.json` and `manual_ai_steering_v2.json` now hold versioned, stable-ID parameters for the shared yaw/grip solver and AI's signed-yaw route controller. These are one authoritative candidate data source; test code loads the resources rather than duplicating its values. The AI controller only requests yaw. Both player and AI must still pass through the same physics, full-body and course-edge admission before race progress is awarded.

A deterministic geometry probe starts on the actual Woodland Mass Start route and drives the candidate AI with 4 and 7 m/s constant speed through the first 940 m, before the firing-range entry. At each fixed tick it projects only onto the selected route occurrence and checks the **full body radius plus edge clearance** inside authored width. Both speeds reached 940 m. Maximum centre-line offset was 1.16 m at 4 m/s and 1.76 m at 7 m/s. The first candidate lost its local projection at 7 m/s around the first turn; increased lookahead and faster heading response resolved that isolated failure. This is a geometry/controller check, not a valid race-time, realistic variable-speed, contact, slope, snow or fatigue benchmark.
