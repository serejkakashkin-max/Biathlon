# WP-177 — короткий спуск Woodland и физический подход к рубежу

Дата: 2026-10-07. Статус: **проверенный отдельный кандидат; WP-177 и M13 OPEN**.

После сокращения прямого окна спуска с 140 до 80 м первый полный Mass Start 30 остановил спортсмена у `mat_23` на 181 тик. Причина не была числовой задержкой рубежа: сосед на общей мировой траектории блокировал поперечный переход при положительном запросе усилия. В AI добавлено узкое реактивное правило: только после доказанного телесного конфликта на общем подъезде спортсмен сохраняет уже занимаемую линию на один тик. Авторитетное поле по-прежнему решает, разрешено ли движение; правило не переносит тело, не выдаёт ускорение и не ослабляет физический контакт. Более широкий упреждающий вариант дал 221 тик остановки и отвергнут.

Кандидат теперь воспроизводится из отслеживаемых рецептов командой `python scripts/content/m13/build_short_course_review_candidate.py --output-root artifacts/<новый-каталог>`. Конвейер создаёт маршруты всех форматов, привязывает измеренные guards компактного рубежа, проверяет политику параллельного выезда, пересоздаёт terrain/forest и roadside dressing, затем повторно запускает строгий validator. Независимая пересборка совпала побайтно по всем 89 JSON трассы с проверенным кандидатом. [Рецепт и SHA-256](../quality/m13/wp177-descent-review-20261007/candidate-rebuild-receipt.json), [итоговый validator](../quality/m13/wp177-descent-review-20261007/candidate-venue-validation.json): 0 ошибок; environment verifier PASS. В итоговом окружении 1441 roadside и 45 mesh assets; опасные места ленточных ограждений отсеяны.
