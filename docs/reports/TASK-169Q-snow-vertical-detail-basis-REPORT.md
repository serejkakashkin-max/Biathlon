# TASK169Q — valid snow detail normals on vertical faces

2026-10-02. The bounded snow shader defect is fixed and its GPU regression passes. WP169 and M13 remain IN_PROGRESS; this is not full production visual acceptance.

The climb-forest, snow-edge and side-entry GameView captures showed nearly black snow-edge segments alongside continuous blue shaded lips. Independent source review found outward skirt winding consistent for left, right, start and end faces, with curtains joining the exact terrain cuts. The authored main segment249.048–849.048 has constant X and contains both climb capture positions568/600. Its interior skirt normals are exactly +/-X; actual mat01/mat30 also contain constant-X runs. Reversing the curtain triangles or changing ground heights was therefore not the supported first fix.

`Biathlon/Snow` projected world X onto the surface plane and normalized that projection to construct its detail tangent. For a +/-X normal, the projection is zero. Procedural grain can obscure the case nearby, but its distant fade restores the exact geometric normal. The root's shader change retains the original world-X reference when well-defined and projects world Z instead when the squared tangent length is below `1e-4`. Upward-facing terrain retains the existing basis. Ribbon/skirt geometry, material palettes, lights, course data and simulation behavior are unchanged.

The new `SnowVerticalSurfaceShaderTests` GPU regression renders the actual native snow shader on +X, -X and +Y faces. It uses the groomed packed channel, neutral detail texture and a lit detail-off control; procedural normal perturbation is suppressed to reproduce the exact distant-skirt case. The old shader failed **0/1**, producing +X control luminance0.8630233 and detail luminance0.0. Its black image, numerical evidence and failed result remain archived. After the fallback the same test passed **1/1**,0failed/0skipped,0.502s; detail/control luminance ratios are **1.001112 (+X)**, **1.000955 (-X)** and **1.001363 (+Y)**. The193 discovered tests are not a full PlayMode result.

Root ran compilation/test through direct Unity MCP tools after the PowerShell MCP wrapper became unavailable. The failed wrapper application-state query is not evidence of editor or compilation success. The focused native test proves that the shader compiled and rendered these witnesses; a separate final Console/full PlayMode result is root-owned and not claimed by this snapshot. [Verification with source, result and image hashes](../quality/m13/wp169q-snow-vertical-detail-basis.json) identifies the exact evidence.

This demonstrates the shader failure and its correction on the relevant normals. It does not prove every dark pixel in the production captures had that cause. Terrain clearance still leaves a real lip up to0.344665527m; a continuous shaded wall and its cast shadow may remain independently. No post-fix recapture of all three production cameras or frame-rate qualification is included.
