# M13 — предварительное снижение усилия AI перед поворотом

Статус: проверенный кандидат; **не подключён** к игровому Pack host. WP-177 и M13 открыты, Windows review build не выпускался.

На первых 940 м Woodland Main AI с постоянной подачей 400 Вт получает отказ консервативного непрерывного допуска полного габарита около 71,86 м. Снижение подачи до 300/200/0 Вт только на этом тике всё ещё даёт отказ: уже набранная скорость не исчезает мгновенно. Это отказ доказательства безопасного прохода, а не зарегистрированное физическое столкновение.

Добавлены [версионированная политика](../../Assets/Resources/Biathlon/manual_ai_corner_effort_v1.json) и [планировщик](../../Assets/Scripts/AI/ManualAiCornerEffortPlanner.cs). Планировщик наблюдает изменение направления выбранного маршрута за 70 м; при угле более 0,15 рад предлагает ограничить запрос мощности до 300 Вт. Он не меняет физическую силу, характеристики спортсмена, позицию, yaw или допуск к следующему участку. При исходном запросе 400 Вт отдельный одиночный тест применил это решение на 1574 тиках и прошёл первые 940 м с непрерывным допуском каждого тика. Максимальная наблюдавшаяся скорость — 14,36 м/с. Тесты отдельно проверяют, что ограничение не повышает меньший запрос и не открывает неразрешённый переход секции.

При запечатанной границе секции недоступный lookahead теперь возвращает недействительный план. Это не считается прямой трассой с автоматически разрешённой полной мощностью; следующий путь обязан быть явно допущен другим слоем. Последний участок одиночного probe после 925 м использует отдельный тестовый номинальный запрос и всё равно проходит непрерывную проверку габарита.

Скрытая Unity EditMode проверка AI-класса: **12/12 PASS** после финального изменения; AssetDatabase обновлена, Editor не компилирует, Error Console за последние три минуты пустая. Предыдущий первый .NET запуск выявил недоступный из AI assembly внутренний helper контекста; исправлено локальной сериализацией контекста и повторно проверено.

Отдельная диагностика настоящего скрытого Game View на Woodland Main: на 742,2 м (tick 2910, 29,8 км/ч) и 820,3 м (tick 3060, 43,1 км/ч) трасса и окружение видны, но длительный спуск всё ещё выглядит почти ровной прямой из chase camera. Кадры были просмотрены непосредственно через Unity MCP; файл PNG не сохранён, поэтому это наблюдение, а не закрывающий визуальный артефакт. WP-177 требует доработки читаемости трассы и повторного подтверждения.

Кандидат AI пока подставляет выбранную мощность непосредственно в одиночный force/yaw probe. В production её надо выбирать через общую физиологию и effort controller, затем проверить другие способности спортсменов, снежные профили, весь маршрут, групповой контакт, рубеж, штрафной круг, полноценный v2 replay и player input. Ни безопасность поля из 30–40 спортсменов, ни отсутствие очередей этим тестом не доказаны.
